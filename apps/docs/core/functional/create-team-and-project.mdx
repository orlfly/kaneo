---
title: Create a Team and Project
description: Set up your first team and project structure in Kaneo
---

This guide covers the first functional setup inside Kaneo so your team can begin tracking work immediately.

## 1. Create a team

1. Go to the dashboard and create a new team.
2. Choose a clear team name (usually company, team, or department).
3. Confirm creation and open the team.

## 2. Create your first project

Inside the team Projects page:

1. Click **Create project**.
2. Select the team the project belongs to (this defaults to your active team).
3. Set a project name your team will recognize quickly.
4. Open the project when it appears in the projects list.

If you don't have a team yet, the create-project dialog points you to the user-management area so you can create one first.

## 3. Decide your execution view

Each project supports:

- **Board view** for status-driven execution
- **List view** for compact scanning and sorting
- **Backlog view** for planning and grooming

You can switch views as your workflow changes.
